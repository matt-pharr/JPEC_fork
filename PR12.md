## Goal
Provide Julia entry points matching RDCON’s library interface and integrate FEM workflow into the Julia DCON module.

---

## Scope and deliverables

### 1) Library interface
- Implement Julia APIs corresponding to RDCON’s `lib_interface_*` routines.

### 2) End-to-end integration
- Provide a Julia-level `dcon_interface_run` equivalent.
- Wire FEM path alongside the existing ODE path in `Main` or a dedicated entry point.

### 3) Full regression testing
- Run end-to-end comparisons against Fortran RDCON for multiple reference cases.
